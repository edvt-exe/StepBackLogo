# StepBackLogo

A minimalist daily browser game where you guess the brand. But there's a catch: the logo is zoomed in way too close.

**Status:** Work in progress! Just setting up the repo right now. The actual code is dropping soon.

### The Mechanic
I wanted to make a daily guessing game without complicating things. Here is how it works:
* You start with a massive zoom on a famous logo (like, you only see a red curve and a yellow pixel).
* You get 5 attempts to guess the brand.
* Every time you guess incorrectly, the camera takes a "step back" (zooms out).
* Guess it before the whole image is revealed.

### Tech Stack
Keeping it incredibly simple and fast:
* Pure HTML & CSS
* Vanilla JavaScript
* No frameworks, no databases.
